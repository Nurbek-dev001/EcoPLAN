# EcoPlan Hub — Система планирования расходов пассажирских перевозок

## Краткое описание проекта

**EcoPlan Hub** — это автоматизированная система управления бюджетом пассажирских перевозок АО «НК «КТЖ», заменяющая ручные расчеты в Excel на интеллектуальную платформу с централизованным управлением тарифами и строгим контролем нормативов.

interface TemporalData<T> {
  value: T;
  validFrom: Date;      // Дата начала действия
  validTo: Date | null; // Дата окончания (null = действует до сейчас)

### 5. **Логирование всех изменений (Audit Log)**

```typescript
interface AuditLog {
  id: string;

  userId: string;
  action: "create" | "update" | "approve" | "reject" | "archive";
  entityType: "calculation" | "tariff" | "norm" | "expense";
  entityId: string;
  changes: {
    field: string;
    oldValue: unknown;
    newValue: unknown;
  }[];

}
```

**Функции:**
- `logAuditEvent()` — логирование события

**Файлы:** [src/lib/audit-log.ts](src/lib/audit-log.ts)

### 6. **Расширенная ролевая модель (RBAC)**

Реализовано 5 ролей вместо 3:

| Роль | Описание | Права |
|------|---------|-------|
| **Менеджер (Manager)** | Ввод данных и расчёт расходов | Редактирование, расчеты |
| **Аналитик (Analyst)** | Анализ и формирование отчётов | Просмотр, анализ |
| **Контролер (РМО)** ⭐ | Проверка и утверждение бюджетов | Одобрение, отклонение, просмотр логов |
| **Администратор НСИ** ⭐ | Управление справочниками и тарифами | Управление тарифами, версионирование |
| **Руководство (Director)** | Просмотр итогов и отчётов | Только чтение, аналитика |

**Функции управления доступом:**
```typescript
canApprove()          // Контролер может одобрить
canManageTariffs()    // Admin NSI может управлять тарифами
canViewAuditLog()     // Checker, Admin, Director видят логи
```

**Файлы:** [src/lib/roles.ts](src/lib/roles.ts)

## 📝 Примечания

1. **На-Premise безопасность:** Система работает локально (localStorage для демо, на практике — БД)
